# UI Studio benchmark corpus

`benchmark.json` defines product archetypes and evidence contracts used to
evaluate changes to UI Studio. It deliberately contains no third-party screen
captures or aesthetic scores.

Create disposable reference and target inputs appropriate to each scenario,
retain evidence according to policy, and provide one result per required
contract. A missing, failed, or evidence-free result does not pass. Partial runs
must identify exactly which scenarios were exercised.
